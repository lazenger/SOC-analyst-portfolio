TryHackMe Room: SOC Team Internal

 Overview
This room simulated a real Security Operations Center (SOC) environment where multiple security alerts were monitored, analyzed, and investigated.

The goal of this exercise was to understand how SOC analysts handle daily security operations, including alert triage, investigation, and escalation decisions.


 Objectives of the Room

- Understand SOC workflow and responsibilities
- Investigate different types of security alerts
- Perform alert triage and prioritization
- Identify suspicious vs normal activity
- Practice basic incident investigation process



 Investigation Approach

During this exercise, I followed a structured SOC investigation process:

1. Reviewed incoming alerts from the system
2. Analyzed logs and event details for context
3. Assessed severity and potential impact
4. Identified suspicious patterns or anomalies
5. Determined whether activity was malicious or benign
6. Documented findings clearly for each case



Types of Alerts Reviewed

- Suspicious login attempts
- Possible brute-force activity
- Phishing-related indicators
- Unusual network traffic behavior
- Endpoint or user activity anomalies



Key Observations

- Many alerts required context before classification
- Not all alerts indicated real threats (false positives were common)
- Correlating logs from multiple sources improved accuracy
- Proper prioritization is essential in SOC environments
- Documentation is critical for escalation and reporting



 MITRE ATT&CK Mapping

- T1078 – Valid Accounts
- T1110 – Brute Force
- T1566 – Phishing
- T1059 – Command and Scripting (context-based scenarios)



 SOC Skills Practiced

- Alert triage and analysis
- Security event investigation
- Log interpretation
- Threat validation
- Incident documentation
- Basic SOC decision-making process


Conclusion

This room demonstrated how SOC analysts operate in a live monitoring environment, where multiple alerts must be investigated quickly and accurately.

It reinforced the importance of structured thinking, context analysis, and careful validation before escalating incidents.



 Personal Takeaway

- I improved my understanding of SOC alert workflows
- I learned how to differentiate between false positives and real threats
- I gained experience in structured incident investigation
- I understand better how SOC teams prioritize security events
