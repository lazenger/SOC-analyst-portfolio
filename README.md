 My SOC Level 1 Journey

This repository is where I document my learning path as I grow into a SOC Analyst.  
It contains my practice labs, investigations, notes, and hands-on exercises from different cybersecurity platforms and tools.

I’m building this step by step as I improve my skills in security monitoring, incident investigation, and threat detection.


 Why I Created This

I started this journey to move from theory into real practical cybersecurity work.  
Instead of just watching videos or reading, I wanted to actually analyze logs, investigate alerts, and understand how attackers behave in real environments.

This repo helps me track my progress and show what I can actually do.



 What I Am Learning

- How SOC teams detect and respond to incidents  
- How to analyze phishing emails and malicious links  
- How to read logs from SIEM tools  
- Basic malware behavior analysis  
- How attackers use techniques from the MITRE ATT&CK framework  
- How to investigate alerts step by step like a real analyst
